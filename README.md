# Task Manager

A task manager built with React and Vite. You can drag tasks into a new order, give each one a priority, and spot overdue ones at a glance.

Live demo: https://task-manager-react-rho-eight.vercel.app

## Features

- Drag and drop to reorder tasks.
- Priority badges, colour coded by urgency.
- Overdue tasks are highlighted.
- Light and dark mode.
- Works on phones and desktops.
- Small animations throughout.

The styling is plain CSS with a neumorphism look. It's deployed on Vercel.

## Run it locally

```bash
git clone https://github.com/Aisha-Aliyu/task-manager-react.git
cd task-manager-react
npm install
npm run dev
```

Then open http://localhost:5173.
